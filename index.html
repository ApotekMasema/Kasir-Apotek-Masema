Sinkronisasi Cloud

Aplikasi ini menyimpan semua data langsung di komputer ini, jadi tetap bisa dipakai penuh (kasir, stok, riwayat, laporan, dll) walau internet mati. Gunakan tombol di bawah untuk menyalin data ke/dari cloud (Firebase) secara manual.

Memeriksa status...

Sinkron ke Cloud: unggah data dari komputer ini ke cloud. Lakukan setiap kali selesai kerja & internet tersedia.
Tarik dari Cloud: timpa data di komputer ini dengan data dari cloud. Gunakan hanya saat membuka aplikasi di komputer/browser baru, atau untuk memulihkan data — perubahan yang belum disinkron di komputer ini akan hilang.

Backup Data

Unduh seluruh data (stok obat, riwayat transaksi, pengaturan) sebagai file cadangan. Simpan file ini di HP/laptop/Google Drive secara berkala (mis. tiap minggu), untuk jaga-jaga kalau data bermasalah.

Catatan: PIN admin tidak ikut disertakan dalam file backup demi keamanan.

⚠️ Ini akan menimpa semua data saat ini (stok obat, transaksi, pengaturan) dengan isi file backup yang dipilih. Pastikan file-nya benar sebelum lanjut.

⚠️ Belum Terhubung ke Database

Aplikasi ini butuh Firebase Database URL supaya data kasir bisa tersimpan & sinkron di semua perangkat.

Caranya:
1. Buat project Firebase baru (terpisah dari aplikasi Absensi), aktifkan Realtime Database.
2. Buka file index.html ini dengan editor teks (Notepad / GitHub).
3. Cari baris const FIREBASE_DB_URL = "TEMPEL_DATABASE_URL_FIREBASE_DI_SINI";
4. Ganti bagian dalam tanda kutip dengan Database URL dari Firebase Anda.
5. Simpan & upload ulang ke GitHub.

Gunakan project Firebase baru khusus untuk data kasir (jangan pakai yang sama dengan aplikasi Absensi).
